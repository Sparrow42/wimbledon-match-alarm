# wimbledon-match-alarm

指定した試合（選手同士の組み合わせ）がESPNの公開スコアボードで「開始前」から「進行中」に変わった瞬間に、Windows PC上で音とポップアップを鳴らして知らせるアラームです。深夜に行われるウィンブルドンの試合を見逃さないために作りました。

## できること

- 60秒間隔（変更可）でESPNの公開API（`site.api.espn.com`）をポーリングし、監視対象の試合ステータスをチェック
- 試合が始まった瞬間（`Scheduled` → `In Progress`）に、Windows標準のアラーム音をループ再生 + 画面最前面にポップアップ表示
- ポップアップの「停止」ボタンを押すまで音・表示が続く
- 監視対象は `config.json` を編集するだけで追加・変更できる（コード変更不要）
- 一度アラームを鳴らした試合は `state.json` に記録され、スクリプトを再起動しても二重に鳴らない

## 必要なもの

- Windows PC
- Python 3.x（標準ライブラリのみ使用。追加インストール不要）

## セットアップ

1. このリポジトリをダウンロード（`git clone` または ZIP展開）
2. Pythonがインストールされていることを確認
   ```
   python --version
   ```
3. `config.json` を開き、監視したい試合を設定する（下記「設定方法」参照）

## 使い方

### 起動

フォルダ内の `start_watch.bat` をダブルクリックするだけ。コンソール画面が開いたまま、監視状況（各試合の現在ステータス）がログ表示され続けます。

コマンドラインから直接起動する場合:
```
python watch_and_alarm.py
```

止めるときはコンソールで `Ctrl+C`。

### 音・ポップアップだけを今すぐテストしたいとき

```
python watch_and_alarm.py --test-alarm
```
API通信をせず、その場でアラーム（音+ポップアップ）を鳴らします。動作確認用です。

## 設定方法（`config.json`）

```json
{
  "poll_interval_sec": 60,
  "watches": [
    {
      "label": "望月慎太郎 vs シナー（4回戦・センターコート第3試合）",
      "league": "atp",
      "players": ["Mochizuki", "Sinner"],
      "enabled": true
    }
  ]
}
```

| 項目 | 説明 |
|---|---|
| `poll_interval_sec` | ポーリング間隔（秒）。デフォルト60秒 |
| `label` | ポップアップやログに表示する試合名（自由記述） |
| `league` | `atp`（男子シングルス）または `wta`（女子シングルス） |
| `players` | 選手の姓（の一部）を2つ配列で指定。両方が試合の対戦カードに含まれるものを検索します（大文字小文字は区別しません） |
| `enabled` | `false` にするとその試合の監視を一時的に無効化 |

新しい試合を追加したいときは、`watches` 配列に同じ形式のオブジェクトを追記するだけです。

## 注意事項

- 試合開始の検知は「ESPNのスコアボードにその試合が `In Progress` として反映されたタイミング」に依存します。反映まで数十秒〜数分のラグが出ることがあります。
- 大会期間中（予選〜決勝）の全試合データがAPIレスポンスに含まれるため、初戦から順に該当の対戦カードを検索しています。トーナメント表がまだ確定していない段階（対戦相手未定など）では試合が見つからない旨がログに表示されます。
- 監視は同じPC・同じネットワークで実行し続ける必要があります（スリープ状態だとポーリングが止まります。電源設定でスリープを無効にするか、就寝前にPCを起こしたままにしておいてください）。
